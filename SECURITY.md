# Security Policy

## Supported Versions

Herd Herdr is a reference sample rather than a versioned product. Security fixes are applied on a best-effort basis to the current `main` branch only.

| Version               | Supported |
| --------------------- | --------- |
| Current `main` branch | Yes       |
| Archived revisions    | No        |

## Reporting a Vulnerability

Please use [GitHub's private vulnerability reporting](https://github.com/Gryczka/herd-herdr/security/advisories/new) so details are not exposed in a public issue. Use a regular GitHub issue only for non-sensitive security hardening suggestions.

Include the affected file or URL, reproduction steps, potential impact, and any suggested mitigation. Do not include credentials, tokens, or personal data.

## Response Timeline

We will acknowledge receipt within 48 hours and aim to provide a fix within 7 days for critical issues. Because this is a best-effort reference sample, lower-severity reports may take longer.

## Disclosure Policy

Please allow time for a fix before public disclosure. Once a correction is available, we will coordinate disclosure and credit the reporter unless anonymity is requested.
