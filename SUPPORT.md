# Support

> This project is shared as a reference sample. It is not actively maintained, and there is no guaranteed response time. Support is best-effort via [GitHub Issues](https://github.com/Gryczka/herd-herdr/issues); please do not expect a fast turnaround.

## Questions

Read the [README](README.md) first for architecture, setup, configuration, and usage guidance. If the documentation does not answer your question, open a GitHub issue with enough context for someone else to reproduce your setup.

## Bug Reports

Use the [bug report template](https://github.com/Gryczka/herd-herdr/issues/new?template=bug_report.md) and include:

- Browser and operating system
- Steps to reproduce the problem
- Expected and actual behavior
- Console errors and screenshots when relevant

## Cloudflare Platform Support

For questions about Workers or Wrangler that are not specific to this sample, use the [Cloudflare Workers documentation](https://developers.cloudflare.com/workers/) and official Cloudflare support channels.
